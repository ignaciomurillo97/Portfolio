# Cloud Helper

## Internal cloud resource portal

**Intel**

Cloud Helper was an internal portal for teams to request cloud resources across public cloud providers and internal cloud offerings. The project combined a web interface with backend automation to make provisioning requests more consistent and easier to track.

### Highlights

- Built workflows for requesting cloud resources
- Supported Azure, AWS, GCP, and internal cloud offerings
- Connected user requests to provisioning automation
- Focused on making infrastructure access easier for internal teams

### Technologies

React, Node.js, PostgreSQL, Docker, and cloud platform integrations.
