# Cloud Helper

## Internal cloud resource portal

**Intel**

Cloud Helper was a self-service platform for internal teams to request and provision cloud resources across Azure, AWS, GCP, and internal cloud offerings. It combined a web interface with workflow automation and reporting to standardize approvals, reduce provisioning friction, and give Intel IT better visibility into infrastructure demand.

### Highlights

- Built self-service workflows for requesting cloud resources
- Supported public cloud providers and internal offerings
- Connected requests to provisioning automation and approval paths
- Reduced support overhead for internal infrastructure teams
- Enabled initiative tracking and operational reporting across the organization

### Technologies

React, Node.js, PostgreSQL, Docker, and cloud platform integrations.
