# PubSub SDK

## Standardizing message contracts

**Microsoft**

The PubSub SDK standardized message schemas for Teams Management Infrastructure. It provided robust contracts for distributed messaging scenarios and helped partner teams adopt consistent patterns across their services.

### Highlights

- Designed contracts for dead-letter queues
- Supported out-of-order message delivery
- Enabled replay and rollback workflows
- Handled high-volume backfills
- Built CI/CD and testing workflows for partner adoption

### Technologies

.NET, C#, Azure, distributed messaging, and CI/CD tooling.
