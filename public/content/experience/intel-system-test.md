# Intel: System Test Modernization

## Software Engineer

**2020 - 2021**

Contributed to modernization of system-test software that validated every CPU manufactured by Intel. This included building and maintaining a compiler for a domain-specific test package language and creating data pipelines that informed CPU binning and manufacturing quality decisions in a high-cost validation environment where reliability and efficiency were critical.

### Focus areas

- Compiler tooling
- Test automation
- Quality and reliability
- Data-driven validation
